# Security

ZoneSnap needs the macOS **Accessibility** permission to move and resize
windows. It has no network code, collects nothing, and only reads and writes
`~/Library/Application Support/ZoneSnap/zones.json` and its own preferences.

If you find a security problem, please do not open a public issue. Use
GitHub's "Report a vulnerability" button on the Security tab of this
repository, and include the steps to reproduce it.
