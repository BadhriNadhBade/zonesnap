# Changelog

All notable changes are listed here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.1.0] - 2026-11-15

### Added
- Snap zones with global shortcuts (Ctrl+Option by default). Pressing a key
  again cycles through that key's zones.
- Separate zone sets for landscape and vertical screens.
- Drag a window to a screen edge or corner to snap it, with a preview.
- Neighbor windows follow when you drag a window's edge, so no gap is left.
- One native menu bar menu, a settings window, and an optional login item.
- Works on macOS 12 (Monterey) and later; builds with the Command Line Tools.
