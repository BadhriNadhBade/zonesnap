Snap windows into place.

ZoneSnap is a free menu-bar app for macOS. Press a shortcut or drag a window to a screen edge. It understands rotated monitors, so one window can sit on top and another below.

Install ZoneSnap View source

Free and open source (MIT). Built for macOS 12 or later.

Left half

Every shortcut is Control + Option plus one key.

Press the same key again to cycle through the sizes for that key. ZoneSnap picks the set from the screen the window is on.

Made for desks with more than one screen.

Nothing to configure to start. Everything is adjustable when you want it to be.

Drag to snap

Drag a window to an edge or corner and a preview shows where it will land. Release to snap, or hold Shift to cancel.

Neighbors follow

Resize one window and the window next to it fills the gap, so you don't leave slivers of desktop behind.

Vertical screens

Rotated monitors get their own zones: top, middle and bottom, instead of left and right.

Your own zones

Turn zones on or off, change keys, and set exact positions and sizes in Settings.

Private by design

No account and no network access. Zones are saved in a single file in your Library folder.

Out of the way

It lives in the menu bar with no Dock icon, and can open at login.

Install in three steps.

You need a Mac running macOS 12 or later and the free Command Line Tools. You don't need Xcode.

  1. Build and open the app

    This builds ZoneSnap, puts it in your Applications folder and opens it.

    # skip this line if you already have the Command Line Tools
xcode-select --install

git clone https://github.com/BadhriNadhBade/ZoneSnap.git
cd ZoneSnap
./scripts/install.sh

  2. Allow Accessibility

    Open System Settings, then Privacy & Security, then Accessibility, and turn ZoneSnap on. This is what lets it move windows.

  3. Try it

    Press Ctrl Option ← on any window.

Questions

Which versions of macOS does it support?

ZoneSnap is built for macOS 12 (Monterey) and later, and has been tested on macOS 12. If you try it on a newer version, please tell me how it went.

Why does it need Accessibility access?

macOS only lets apps move and resize other apps' windows with that permission. ZoneSnap uses it for nothing else.

Does it collect any data?

No. There is no account, no analytics and no network access. The source is open, so you can check.

A shortcut does nothing. What now?

Another app may already use it, so change the key in Settings. If none of them work, open the ZoneSnap menu: if it starts with a warning about Accessibility, click it and turn ZoneSnap on. After a rebuild the old entry can go stale, so remove it with the minus button and add it again.
